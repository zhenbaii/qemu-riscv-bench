# Archived measurements

These are the measurements of 2026-11-06, exported when the standalone
repository was assembled. Read [the experiment description](../../docs/historical-vsetvli.md)
for exact revisions, timing scope, controls, and limitations.

`<workspace>` replaces the original machine-local workspace path. The hostname
was omitted from `package-metadata.json`. All numeric measurements and hashes
were retained. `source-hashes.json` hashes the original files, before this
normalization. This export does not contain the complete original logs or
binary artifacts and is not a fresh measurement of the reorganized scripts.
